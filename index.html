Правила

Строгие правила выдачи ролей

Эти условия действуют для всех уровней. Нарушение любого пункта ведёт к отказу.

Только своё

Запрещено: Toolbox, чужой код

Весь код написан тобой. Скрипты из Toolbox, чужие системы и код, который ты не можешь объяснить, считаются чужими. Если это подтвердилось, заявку отклоняют и закрывают подачу на 30 дней.

Бэкдоры и скрытый код

Снятие роли навсегда

Скрытые вызовы, require по чужому ID модуля, loadstring и любой код, который даёт кому-то доступ к игре, запрещены. За это роль снимают без права повторной подачи.

Роли по порядку

Нельзя пропускать уровни

Сначала начинающий, потом средний и так далее. Заявку на следующую роль можно подать не раньше чем через 14 дней после получения предыдущей.

Одна попытка за срок

7 / 14 / 21 / 30 дней

После отказа повторную заявку принимают только через срок из таблицы выше. Заявки, поданные раньше, не рассматривают.

Устная проверка

Объясни и измени код

Модератор вправе открыть твой код и попросить объяснить его строка за строкой, а затем внести небольшое изменение в реальном времени. Отказ или неспособность объяснить приравниваются к отказу в роли.

Все пункты обязательны

Без исключений

Роль выдают только при выполнении каждого пункта чек-листа. Если не хватает одного, заявку отклоняют, даже когда остальное сделано отлично.

Роль можно потерять

Активность 60 дней

Роль снимают за плагиат, обман при проверке и нарушение правил сервера. Со среднего уровня и выше нужна активность: минимум одна новая система за 60 дней, иначе роль понижают на один уровень.

local Players = game:GetService("Players")
local Remote = game.ReplicatedStorage.Remotes.BuyItem

local PRICES: { [string]: number } = { Sword = 100, Shield = 80 }
local lastCall: { [Player]: number } = {}

Remote.OnServerEvent:Connect(function(player: Player, itemName: unknown)
	if typeof(itemName) ~= "string" then return end
	local price = PRICES[itemName]
	if not price then return end

	local now = os.clock()
	if now - (lastCall[player] or 0) < 0.5 then return end
	lastCall[player] = now

	local stats = player:FindFirstChild("leaderstats")
	local coins = stats and stats:FindFirstChild("Coins")
	if not coins or not coins:IsA("IntValue") or coins.Value < price then return end

	coins.Value -= price
	-- выдача предмета
end)

Players.PlayerRemoving:Connect(function(player)
	lastCall[player] = nil
end)

--!strictOnServerEventПроверка данных

--!strict
local Weapon = {}
Weapon.__index = Weapon

export type Weapon = typeof(setmetatable(
	{} :: { damage: number, cooldown: number, _last: number },
	Weapon
))

function Weapon.new(damage: number, cooldown: number): Weapon
	return setmetatable({ damage = damage, cooldown = cooldown, _last = 0 }, Weapon)
end

function Weapon.canFire(self: Weapon): boolean
	return os.clock() - self._last >= self.cooldown
end

function Weapon.fire(self: Weapon, target: Humanoid)
	if not self:canFire() then return end
	self._last = os.clock()
	target:TakeDamage(self.damage)
end

return Weapon

--!strict
local Signal = {}
Signal.__index = Signal

function Signal.new()
	return setmetatable({ _handlers = {} :: { (...any) -> () } }, Signal)
end

function Signal:Connect(fn: (...any) -> ())
	table.insert(self._handlers, fn)
	return function()
		local index = table.find(self._handlers, fn)
		if index then
			table.remove(self._handlers, index)
		end
	end
end

function Signal:Fire(...: any)
	for _, fn in table.clone(self._handlers) do
		task.spawn(fn, ...)
	end
end

return Signal

--!strict
local Janitor = {}
Janitor.__index = Janitor

function Janitor.new()
	return setmetatable({ _items = {} :: { any } }, Janitor)
end

function Janitor:Add(item: any): any
	table.insert(self._items, item)
	return item
end

function Janitor:Destroy()
	for _, item in self._items do
		if typeof(item) == "RBXScriptConnection" then
			item:Disconnect()
		elseif typeof(item) == "Instance" then
			item:Destroy()
		elseif type(item) == "function" then
			item()
		end
	end
	table.clear(self._items)
end

return Janitor

Критерии

На что смотрят при проверке

Эти шесть пунктов проверяют на любом уровне. Если два пункта ниже нормы, заявку отклоняют. Чем выше роль, тем строже оценка.

Читаемость

Понятные имена переменных и функций, ровные отступы, комментарии там, где логика неочевидна. Одна функция решает одну задачу.

Безопасность

Сервер не доверяет клиенту. Всё, что пришло из RemoteEvent, проверяется по типу, диапазону и правам игрока.

Обработка ошибок

Вызовы DataStore и сетевые запросы обёрнуты в pcall. Нет ошибок и предупреждений в Output, проверки на nil стоят там, где значения могут отсутствовать.

Скорость

Нет лишних циклов, события отключаются через Disconnect, ссылки на объекты кешируются. Тяжёлые вычисления не блокируют кадр.

Структура

Серверный код лежит в ServerScriptService, клиентский в StarterPlayerScripts, общие модули в ReplicatedStorage. Повторяющийся код вынесен в ModuleScript.

Современный Luau

Используется task library вместо wait, spawn и delay. Parent задаётся после настройки свойств. На высоких ролях добавляются типы и --!strict.

Заявка

Как получить роль

  1. Выбери рольПройди чек-лист выше и отметь, что уже выполнено.
  2. Собери портфолиоКод, видео работы и ссылка на Place. Для каждой системы напиши, что она делает и как устроена.
  3. Отправь заявкуСкопируй шаблон справа, заполни все поля и отправь модераторам. Заявки с пустыми полями не рассматривают.
  4. Получи решениеМодераторы выдадут роль или напишут причину отказа. Повторная заявка возможна только после срока из правил.
